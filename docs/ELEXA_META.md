## VI. GAME LOOPS

### Tap-to-Earn
- `/tap` → Move within current region, +15 XP
- Boss encounters at tile 20 of each region
- Region-specific hazards and loot multipliers apply
- Party HP shared, roles affect abilities

### MMO Squad Roles (Party System)
| Role | Ability | Synergy |
|------|---------|---------|
| Vanguard ⚔️ | +20% DMG to bosses | DPS core |
| Bulwark 🛡️ | +30% DMG reduction | Tank/Aggro |
| Guardian 🌿 | Heal party on tap | Support |
| Scout 🔭 | +Encounter & loot rate | Discovery |

**Synergy Bonus:** Full squad (4 members) with 4 unique roles = **1.5× XP/Rep/Loot**. Mixed full squad = 1.1×.

### Party System
- Create squads, invite members (max 4)
- Role selection: Vanguard, Bulwark, Guardian, Scout
- Synergy bonus calculated per-action

### Raid System
- Social raids against external targets
- Report participation → earn rewards
- Rewards: XP, reputation, loot
- Coordinated via Party Window

### Economy
- **EXP**: Earned via taps, holds, engagement, raids, buys
- **Soul Dust**: Used for Soul Traps, town buildings
- **Heroic Cred**: Earned via legendary deeds (nat 20s, artisan mastery)
- **Decay**: Inactivity fades reputation (anti-whale)
