# Elexa Live: Solana PDA World Architecture 

## Overview
This document defines the 19 Program Derived Accounts (PDAs) that form the state of the Elexa Live metaverse, and the synchronization loop between the on-chain state and the OpenClaw AI agent ("Game Master").

## 1. Core State (The "Big 5")
These singletons govern global parameters and high-level assets. deploy these first.

### 1.1 `GlobalWorld` (Singleton)
- **Seeds:** `["global", "alexa_live_2026_02_17"]`
- **Owner:** Program
- **Data:**
  - `admin_authority`: Pubkey (Mutli-sig / DAO)
  - `treasury_link`: Pubkey (`JEFEXVZDh43U8eE27geg4wWPBJaBzTDyyyk15CVzvDy6`)
  - `last_tick`: i64 (Unix timestamp)
  - `weather_state`: Enum { Sunny, Storm, NebulaMist, SolarFlare }
  - `market_phase`: Enum { Seed, Growth, Correction, Expansion }
  - `citizen_count`: u64
  - `max_citizen_limit`: u64

### 1.2 `Treasury` (Vault)
- **Seeds:** `["treasury"]`
- **Owner:** System (PDA Signer)
- **Function:** Holds SOL, $EXP, and Project Tokens.
- **Address:** `JEFEXVZDh43U8eE27geg4wWPBJaBzTDyyyk15CVzvDy6`
- **Funds:** Births (0.01 SOL), Guild Tax (2%), Market Fees.

### 1.3 `UserRegistry` (Player Index)
- **Seeds:** `["user", wallet_pubkey]`
- **Data:**
  - `elexa_id`: String
  - `wallet`: Pubkey
  - `reputation`: i64
  - `joined_at`: i64

### 1.4 `Citizen` (The Living Population)
**Note:** Represents both Players (living) and NPCs. Differentiated by `owner` field.
- **Seeds:** `["citizen", unique_id]`
- **Data:**
  - `id`: u64
  - `owner`: Pubkey (Wallet for Players, or System/Program for NPCs)
  - `type`: Enum { NPC, Player }
  - `lifespan`: i64 (Ticks until death; 0 for Players)
  - `name`: String
  - `role`: Enum { Vagabond, Miner, Trader, Artist, Architect, Warlord, Mystic }
  - `vision`: String (e.g. "Decentralization")
  - `is_founder`: Bool (True for first 7)
  - `birth_tick`: i64
  - `hp`: u8
  - `morale`: u8
  - `stats`: Struct { Strength, Intellect, Charisma, Luck }
  - `inventory`: Vec<Pubkey> (Top 5 items held)
  - `parents`: [u64; 2] (Mocked for Gen0)

### 1.5 `Council` (Financial Sovereigns)
- **Seeds:** `["council"]`
- **Data:**
  - `members`: [CouncilMember; 5]
    - `wallet`: Pubkey
    - `role`: Enum { Arbiter, Sentinel, Oracle, Keeper, Void }
    - `strategy`: Enum { Aggressive, Passive, Sniper, Hype }
    - `volume_generated`: u64

## 2. Sub-PDAs (The Simulation Layer)
Auto-spawned by user actions or ticks.

### 2.1 `Citizen` (NPC Extended Data - Optional)
*Deprecated in favor of unified 1.4 struct. If distinct NPC behavior is needed, use `role` Enum.*

### 2.2 `Family`
- **Seeds:** `["family", family_id]`
- **Data:** `members`, `house`, `shared_wealth`.

### 2.3 `Plot` (Land Hex)
- **Seeds:** `["plot", ring, x, y]`
- **Data:** `owner`, `build_level`, `roads_connected`, `citizens_inside`.

### 2.4 `Building`
- **Seeds:** `["building", plot_id, type]`
- **Data:** `type`, `level`, `production_rate`, `citizens_inside`.

### 2.5 `Road`
- **Seeds:** `["road", plotA, plotB]`
- **Data:** `connected`, `upkeep`.

### 2.6 `Item` (Loot - cNFT Wrapper)
*High Volume Asset: Implemented as Compressed NFTs (cNFTs) to save state.
Strategies:
1. **NPC Trading**: NPCs trade up basic loot (e.g., 3x "Rusty Ore") -> 1x "Refined Ingot".
2. **Marketplace**: High-value items (Rares/Legendaries) listed on Soul Swap.
3. **Usage**: Consumed for crafting or reputation.*
- **Seeds:** `["item", mint_address]` (Only if state tracking needed)
- **Data:** `type`, `quality`, `owner`.

### 2.7 `Market`
- **Seeds:** `["market", ring]`
- **Data:** `listings` (item/price/seller).

### 2.8 `UserAsset` (Land & Elexamon)
*Persistent User Assets minted as Standard NFTs or PDAs depending on logic.*
- **Land (Plot)**: The user's slice of the metaverse.
  - **Seeds:** `["plot", region, x, y]`
- **Elexamon**: The user's companion.
  - **Seeds:** `["elexamon", mint_address]`
  - **Data:** `species`, `level`, `xp`, `shiny`, `moves`.

### 2.8 `Faith`
- **Seeds:** `["faith", god_name, ring]`
- **Data:** `followers`, `tithe_rate`, `relics`.

### 2.9 `Relic`
- **Seeds:** `["relic", faith_id, relic_id]`
- **Data:** `type`, `power`, `owner`.

### 2.10 `Guild` (Meme Companies / Tribes)
- **Seeds:** `["guild", name]`
- **Data:** 
  - `leader`: Pubkey (Godlike Trader)
  - `token_mint`: Option<Pubkey> (e.g., BONK, WIF Mint Address)
  - `liquidity_score`: u64 (Total volume generated by members)
  - `members`: u32
  - `territory`: Vec<Pubkey> (Plots owned)
  - `war_status`: u8

### 2.11 `Vote`
- **Seeds:** `["vote", proposal_id]`
- **Data:** `proposal`, `voters`, `result`.

### 2.12 `Event`
- **Seeds:** `["event", id]`
- **Data:** `trigger`, `duration`, `participants`, `reward`.

### 2.13 `Weather`
- **Seeds:** `["weather", ring]`
- **Data:** `type`, `duration`, `effect`.

### 2.14 `Ghost`
- **Seeds:** `["ghost", citizen_id]`
- **Data:** `whispers`, `haunt_location`.

## 1. Core State (The "Big 5" - Launch Ready)
1. **GlobalWorld** (Singleton): Time, Weather, Phase.
2. **Treasury** (Vault): SOL, Tax, Funds.
3. **UserRegistry** (Player): Identity, Reputation.
4. **Citizen** (Population): The core living unit (Player + NPC).
5. **Council** (Sovereigns): Market Makers.

## 2. Life & Society (The Simulation)
6. **Citizen**: NPC state (Role, Vision, Founders).
7. **Family**: Linkage between Citizens (Parents, Children).
8. **Relationship**: Romance/Partnership state (Love).
9. **BirthRecord**: Registry of a new life (Certificate).
10. **Ghost**: Post-death state (Wisdom/Haunting).
11. **FuneralMarker**: Grave/Memorial (Morale buff).

## 3. Economy & Work
12. **JobLicense**: Specific profession stats (Blacksmith lvl, etc.).
13. **Item**: Unique objects (Relics, Bread).
14. **MarketListing**: Active sell orders.
15. **Plot**: Land Hex state.
16. **Building**: Structures on Plots.

## 4. Religion & Purpose
17. **Faith**: A Religion instance (e.g., Church of Pepe).
18. **Relic**: Holy items attached to Faith.
19. **Ritual**: Active group event state.
20. **Heresy**: Mark of shame/exile.

## 5. Governance
21. **Vote**: Active proposal state.
